# Task `ios` (owner: codex)

Build the native iOS keyboard in `ios/` plus a GitHub Actions workflow that compiles it on macOS. There's no Mac or Apple account yet: everything must be generated from text files and built in CI. Read `AGENTS.md` and `spec/layout.json` first. Run `node tools/sync-spec.mjs` after creating `ios/` so `ios/Keyboard/layout.json` exists, and bundle it as a resource. Never hard-code the layout.

## Project
- `ios/project.yml` for **XcodeGen**: an app target `TrustChainKeyboard` (bundle id `mn.trustchain.keyboard`, iOS 15+, Swift 5) and an app-extension target `Keyboard` (bundle id `mn.trustchain.keyboard.ext`, extension point `com.apple.keyboard-service`), embedded in the app. Display name "TrustChain Keyboard". Don't commit a generated `.xcodeproj`; gitignore it.
- Extension `Info.plist`: `NSExtensionAttributes` with `IsASCIICapable` = NO, `PrefersRightToLeft` = NO, `PrimaryLanguage` = `mn`, **`RequestsOpenAccess` = NO**. The principal class is the keyboard view controller.
- **Container app** (UIKit, one screen, Mongolian text): the logo plus 3 setup steps (Settings → General → Keyboard → Keyboards → Add New Keyboard → TrustChain Keyboard), a button that opens `UIApplication.openSettingsURLString`, a test text field, and the privacy promise. Include an app icon set (generated from the TrustChain logo at the required sizes; you can render PNGs with a script) so archive validation won't fail later.
- **Keyboard extension** (`UIInputViewController`, UIKit, custom views): the layout from layout.json, with letters, shift (tap = one capital, double tap = caps lock), backspace (hold to repeat, accelerating), the symbols layer, space, return (using `textDocumentProxy` return-key type), comma/period with long lists, and auto-capitalisation per `rules` and `textDocumentProxy.autocapitalizationType`. A globe key only when `needsInputModeSwitchKey` is true (use `handleInputModeList(from:with:)`).
  - **Long-press is the core feature:** after `longPressMs` a popup bubble appears above the key, showing the `long` options with the first preselected. Sliding the finger changes the selection, releasing types it, and a quick tap types the base letter. Handle touches in one place (a single touch-tracking view) so it's fast. Keys at the screen edge keep the popup on screen. Add key-press haptics only if available without full access (`UIDevice.current.playInputClick()` with `UIInputViewAudioFeedback`), with no network and no storage of typed text.
  - Top bar: a small "TrustChain" brand label on the left, and a share button on the right that inserts nothing. On iOS an extension can't open URLs without full access, so the share button shows a small tooltip with the text "trustchain.mn/keyboard" instead. Keep it simple.
  - Light and dark appearance that follows `textDocumentProxy.keyboardAppearance` and the trait collection.
- `.github/workflows/ios.yml`: on push to main and workflow_dispatch, run on `macos-latest`: `brew install xcodegen` → `xcodegen` in `ios/` → `xcodebuild -scheme TrustChainKeyboard -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build`. Then boot a simulator, install the app and take a screenshot with `xcrun simctl io booted screenshot`, uploaded as an artifact (best effort, `continue-on-error`). Add a second job `testflight` that only runs on workflow_dispatch with input `upload=true` and when the secrets `ASC_KEY_ID`, `ASC_ISSUER_ID` and `ASC_KEY_P8` exist. It archives with `-allowProvisioningUpdates -authenticationKeyPath … -authenticationKeyID … -authenticationKeyIssuerID …`, exports with method `app-store-connect`, and uploads with `xcrun altool --upload-app` (or `xcrun notarytool`-style API key auth for upload). Include `ios/ExportOptions.plist`. Document the secrets in `ios/README.md`.

## Checks before finishing
- `node --test spec/*.test.mjs` passes.
- No Swift compiler is available here, so review your own Swift carefully for compile errors (imports, optionals, `override` keywords, `@objc` selectors). CI is the real check.
